# 🏥 Sakthi MultiCare Clinic Website

This project is a **multi-speciality clinic website** built as part of my **Frontend Web Development Internship (Task 3)**.

The goal of this project was to create a simple and practical website that represents how a real clinic might present its services online.

---

## 🚀 Features

- Basic and clear navigation (Home, About, Services, Doctors, Contact)
- Appointment booking section (UI)
- Symptom checker (basic logic-based feature)
- Simple chat assistant for common queries
- Clean and minimal design (no heavy styling or animations)

---

## 🛠️ Technologies Used

- HTML  
- CSS  
- JavaScript  

---

## 💡 What I Learned

- Structuring a real-world website layout  
- Connecting multiple sections into one flow  
- Implementing simple logic using JavaScript  
- Keeping UI clean and user-friendly
